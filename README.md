# 💻 Portfólio — Victor Hugo

Este projeto consiste no meu **portfólio pessoal**, desenvolvido para apresentar minha trajetória acadêmica e profissional, minhas principais competências e projetos desenvolvidos na área de tecnologia.

O objetivo é reunir, em um único espaço, informações sobre minha formação, conhecimentos técnicos e projetos, além de disponibilizar meus canais de contato e redes profissionais.

## 🚀 Sobre o projeto

O portfólio foi desenvolvido como uma aplicação web responsiva, com uma interface simples e moderna, buscando proporcionar uma navegação intuitiva e apresentar minhas experiências e conhecimentos de forma organizada.

Entre as informações apresentadas estão:

* 👨🏻‍💻 Sobre mim e minha trajetória na tecnologia
* 🛠️ Competências e tecnologias
* 📂 Projetos desenvolvidos
* 📊 Conhecimentos em Dados e Business Intelligence
* ⚙️ Conhecimentos em Power Platform
* 📫 Formas de contato e redes profissionais

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Typed.js
* ScrollReveal
* Unicons

## 📂 Projetos apresentados

O portfólio reúne alguns dos projetos desenvolvidos ao longo da minha trajetória, incluindo projetos de desenvolvimento web realizados durante o curso técnico de Informática para Internet.

Entre eles estão:

* **Primeiro Site** — meu primeiro projeto web.
* **VP-Acessórios** — projeto desenvolvido em dupla durante o curso técnico.
* **NextGen Consultoria** — projeto desenvolvido em equipe como TCC.

## 🎯 Objetivo

Este projeto também funciona como uma forma de acompanhar minha evolução na área de tecnologia, reunindo conhecimentos adquiridos em **desenvolvimento, programação, dados, Business Intelligence, automação e Power Platform**.

O portfólio será atualizado conforme novos projetos e competências forem desenvolvidos.
